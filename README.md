# Plywood Home

A modern, elegant e-commerce website for premium plywood and architectural surfaces. Built with React, TypeScript, and Vite.

## 🌟 Features

- **Responsive Design** - Beautiful UI that works on all devices
- **Product Showcase** - Interactive product galleries and carousel
- **Catalogue Downloads** - Easy access to PDF catalogues
- **Collections** - Organized product collections
- **FAQ Section** - Comprehensive frequently asked questions
- **Contact Integration** - Multiple ways to get in touch
  - WhatsApp chatbot
  - Email contact form
  - Direct phone & address
- **Admin Panel** - Secure admin route for management
- **Performance Optimized** - Fast loading with Vite

## 🛠️ Tech Stack

- **Frontend Framework** - React 18
- **Language** - TypeScript
- **Build Tool** - Vite
- **Styling** - Tailwind CSS
- **UI Components** - Shadcn/ui
- **Routing** - React Router v6
- **Animations** - Lenis smooth scroll
- **Testing** - Vitest

## 📦 Installation

1. **Clone the repository**
```bash
git clone https://github.com/Biswajitn23/plywood.git
cd plywood_home-main
```

2. **Install dependencies**
```bash
npm install
# or
bun install
```

## 🚀 Running the Project

**Development mode:**
```bash
npm run dev
```
The app will be available at `http://localhost:8080`

**Build for production:**
```bash
npm run build
```

**Preview production build:**
```bash
npm run preview
```

**Run tests:**
```bash
npm run test
```
